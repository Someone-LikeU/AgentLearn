# 本地语义搜索技能

智能搜索本地文件，支持语义理解和内容匹配。

## 功能特性

- 语义搜索：理解查询意图，匹配相关文件
- 内容索引：扫描文件名和内容构建向量索引
- 多格式支持：txt, md, pdf, docx, pptx 等
- 灵活范围：默认当前目录，可扩展到全盘
- 目录索引检查：自动检测指定目录是否已向量化
- 增量/全量刷新：支持用户选择索引更新方式

## 工作流程

### 用户指定目录搜索时

当用户说"帮我在某个目录搜索..."时，执行以下流程：

1. **提取目录路径**：从用户请求中识别目标目录
2. **检查索引状态**：使用 `scripts/check_index.py` 检查该目录是否已向量化
3. **提示用户**：
   - 若目录已索引：显示索引信息（文件数、索引时间），询问是否需要刷新
   - 若目录未索引：提示需要构建索引
4. **用户选择刷新方式**：
   - **全量刷新**：删除旧索引，重新扫描所有文件并构建索引
   - **增量刷新**：检测文件变更（新增/修改/删除），只更新变化的文件
   - **不刷新**：使用现有索引直接搜索
5. **执行搜索**：调用语义搜索接口，返回结果

### 默认目录搜索时

当用户未指定目录时：
1. 使用当前已索引的目录
2. 若无索引，询问用户要搜索的目录

### 执行搜索

1. 接收用户查询
2. 调用语义搜索接口
3. 返回结构化结果

## 索引检查

使用 `scripts/check_index.py` 检查目录索引状态：

```bash
python scripts/check_index.py --dir <目录路径>
```

输出示例：
```json
{
  "indexed": true,
  "dir": "/Users/xxx/Documents",
  "total_files": 465,
  "indexed_files": 300,
  "indexed_at": "2026-04-28T15:00:00",
  "file_types": ["txt", "md", "pdf", "docx", "pptx"],
  "status": "partial"
}
```

状态说明：
- `indexed`: true - 目录已索引
- `indexed`: false - 目录未索引
- `status`: "complete" - 索引完整
- `status`: "partial" - 索引部分完成
- `status`: "stale" - 索引过期（有文件变更）

## 索引构建

使用 `scripts/indexer.py` 构建向量索引：

```bash
# 全量刷新
python scripts/indexer.py --dir <搜索目录> --include-content --force

# 增量刷新
python scripts/indexer.py --dir <搜索目录> --include-content --incremental
```

参数说明：
- `--dir`: 搜索根目录，默认当前目录
- `--include-content`: 是否索引文件内容，默认开启
- `--file-types`: 文件类型过滤，逗号分隔
- `--force`: 强制重建索引（全量刷新）
- `--incremental`: 增量更新，只处理变化的文件

索引存储位置：`<skill-dir>/vector_store/`

## 向量库重置

使用 `scripts/reset_vector_store.py` 重置向量库：

```bash
# 查看向量库状态
python scripts/reset_vector_store.py --status

# 重置向量库（需要确认）
python scripts/reset_vector_store.py --reset --force
```

参数说明：
- `--status`: 查看向量库状态（文件数、大小、索引信息）
- `--reset`: 执行重置操作
- `--force`: 确认重置（必须，防止误操作）

重置效果：
- 删除所有向量数据
- 删除索引元数据
- 恢复为初始状态
- 可重新构建索引

适用场景：
- 索引损坏需要重建
- 切换嵌入模型后需要重建
- 清理旧数据重新开始
- 磁盘空间不足需要清理

## 搜索执行

使用 `scripts/searcher.py` 执行搜索：

```bash
python scripts/searcher.py --query "<查询文本>" --top-k 10 --dir <目录路径>
```

参数说明：
- `--query`: 搜索查询文本
- `--top-k`: 返回结果数量，默认10
- `--threshold`: 相似度阈值，默认0
- `--dir`: 指定搜索目录（可选）

## 支持的文件类型

| 类型 | 扩展名 | 内容提取 |
|------|--------|----------|
| 文本 | .txt | 直接读取 |
| Markdown | .md | 直接读取 |
| PDF | .pdf | PyPDF2/pdfplumber |
| Word | .docx | python-docx |
| PowerPoint | .pptx | python-pptx |

## 向量库配置

使用 ChromaDB 作为本地向量数据库：
- 嵌入模型：m3e-base（内置，位于 `models/m3e-base/`）
- 维度：768
- 语言：中文优化
- 离线运行，无需网络
- 距离度量：余弦距离（cosine）

**模型管理**：
- 默认使用skill内置模型，无需配置
- 支持扫描本地其他模型并切换
- 使用 `python scripts/model_manager.py --scan` 查看可用模型

## 注意事项

- 首次索引大型目录可能耗时较长
- 向量库占用磁盘空间（约每1000文件 50-100MB）
- 增量刷新比全量刷新更快，适合日常更新
- 全量刷新适合索引损坏或大量文件变更的情况
- 建议定期检查索引状态，保持索引新鲜度
