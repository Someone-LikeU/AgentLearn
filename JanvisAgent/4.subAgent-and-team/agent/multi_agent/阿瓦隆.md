# 一、游戏简介
阿瓦隆是一款身份推理、语言类、对抗类桌游，需要5-10名玩家参与。具有如下特点：所有玩家全程参与，不会出局；平民可以是游戏中最有体验的角色；无过多游戏术语或黑话；逻辑性强，游戏平衡；发言无套路，沉默亦可作为有效信息。

# 二、玩法概述
- 玩家们会分为两大阵营：【骑士阵营】（或称蓝方/好人阵营） 、【反抗军阵营】（或称红方/坏人阵营）。
- 在游戏正式开始前有一个【夜晚】阶段，所有玩家在该阶段会获取他们各自的初始视野信息。例如：红方玩家会睁眼互认，蓝方有一个类似预言家的角色，他会看到所有红方玩家等。整局游戏有且仅有一个夜晚。
- 游戏的主进程是五轮任务。每轮任务中，所有玩家都需共同商讨，选出一批人去参与该轮【任务】，【任务】只有【成功】或【失败】两种情况，若一轮任务成功记蓝方阵营胜利1次，反之任务失败记红方阵营胜利1次，累积先胜利3次的阵营宣告最终获胜，即五局三胜制。因此蓝方阵营的目标是尽力让每轮任务成功，红方阵营则是要尽可能破坏每轮任务，但所有玩家表面目标一致，即，皆应积极主动参与进每轮任务（积极参与任务并不意味着需要积极发言）。
- 【任务】是什么？所谓任务其实是一个虚拟流程：玩家会轮流担任【队长】一职（也可称车长），在一轮任务中，【队长】需选出一部分玩家参与该轮任务（称之为“定车型”、选人“上车”做任务），然后所有玩家共同【公开投票】表决是否同意由这些玩家上车做任务，若超过半数不同意则顺延下一玩家当【队长】并重新选人然后再次表决，每轮任务若超过3次不同意发车，则第4次不经过所有玩家【公开投票】，由【队长】选人强制执行。一旦【公投】通过（或第4次选人强制执行），这些【上车的玩家】就需一起【匿名】投出【支持】或【反对】，以此来决定该轮【任务】是否成功，蓝方阵营玩家只能投【支持】，红方阵营玩家两种卡都可以选择。【上车的玩家】中如果有任意一名玩家匿名投出了【反对】，本次任务即宣告【失败】，记红方阵营胜利1次；也就是说，任务【成功】需车上所有玩家全部都匿名投出【支持】。
- 在各轮【任务】之间，玩家需通过发言来交换信息，也会通过观察玩家【公投】是否同意“发车”时的表态来判断其身份，也可以通过观察某玩家上车参与任务后、任务的成败情况来猜测该玩家的阵营。蓝方玩家要积极参与进每轮任务中以提高获胜概率，并尽可能识别出红方玩家，阻止其上车参与任务；同样的，红方玩家要隐藏自己的身份积极参与进每轮任务中，匿名投出【反对】来暗中破坏任务。
- 信息流出的核心是“队长组队”、“玩家发言”、“公投表决”、“匿名任务”四个环节，每个环节都会暴露出不同程度的信息，整个游戏是一个不完全信息动态博弈，无论是哪一方阵营的玩家都需要靠多次博弈和推理才能获得更多、更完整的有效信息。每个玩家角色都会在游戏开始时唯一的【夜晚】阶段获得不同的初始视野信息——也就是各个角色能够看到谁、以及被谁看到。

# 三、角色介绍
## 蓝方/骑士阵营
- 【梅林】：类似预言家的角色，在【夜晚】知道所有红方玩家的位置，（除莫德雷德）。梅林的基本玩法是小心隐藏自己，争取派西维尔的信任，向派西维尔暗递信息同时尽量避免暴露自己。由于红方刺客的存在，梅林一旦被刺杀，游戏即宣告结束，因此掌握游戏中最多信息与视角的该角色必须同时低调表现。
- 【派西维尔】：俗称“派”，是蓝方的带队角色。在【夜晚】知道莫甘娜和梅林的位置，但不能分辨二者具体谁是谁。主要任务是尽快分辨莫甘娜和梅林具体是谁，并听取梅林给出的信息，然后带领好人把任务做成。因此该角色的有几种玩法：1、积极发言，大胆表明自己的派西维尔身份（跳派），最好先于莫甘娜跳派，发言时须注意隐藏梅林的位置，必须要保护好梅林，哪怕已自信认出梅林，也务必不要同时点出在【夜晚】时看到的两位角色，因红方角色是互认的，此操作会立即暴露梅林。2、作为“梅林的代言”（装梅林），尽力博得蓝方平民角色的信任并引导他们上车支持。3、对跳，如果在该玩家前置位有一至多位玩家发言时先行跳派，可能是红方阵营的莫甘娜假装，为了试探出谁是梅林，也可能是蓝方角色假装，故意混淆视听，没有把握时不要轻易立即对跳，可能会不小心暴露梅林。（以上玩法仅供参考）
- 【骑士/忠臣】：无特殊视野的蓝方平民角色。该角色玩法灵活，其基本玩法是判断并跟随场上的派西维尔，积极参与任务，将自己装作梅林为梅林打掩护、挡刀，也可以装做派西维尔跳派，故意给出误导信息等。该角色虽无视角信息但可玩性极强。
## 红方/反抗军阵营
- 【莫甘娜】：在【夜晚】与红方队友睁眼互认（除奥伯伦）。因莫甘娜和梅林会同时被派西维尔看到，所以可以假扮梅林。玩法灵活，基本玩法是骗取场上派西维尔的信任，使其将你错认为梅林，然后你可通过给出误导信息，引导红方角色上车破坏任务。也可以假扮派西维尔，引诱真派西维尔发言暴露出真梅林。
- 【刺客】：在【夜晚】阶段与红方队友睁眼互认（除奥伯伦）。刺客拥有整局游戏唯一一次【刺杀】其他角色的机会，其目标是成功刺杀到梅林。因此一旦宣告刺杀，无论刺杀成功与否，游戏都会直接结束，因此您需要在整局游戏的过程中寻找梅林，在没有把握确认之前切莫随意宣告刺杀，避免过早中断游戏导致其他玩家损失体验。即使蓝方已经率先取得3次任务成功即将赢得游戏，也可以在此时进行【刺杀】，若成功刺杀到梅林，则红方反败为胜。游戏中的玩法较为灵活，可任意发挥。
- 【奥伯伦】：是一匹“独狼”。【夜晚】阶段全程闭眼，无法和红方队友互认，红方队友也看不到你。但你仍能被梅林看到。游戏中玩法多样，可任意发挥。你既可以选择尽快暴露自己的红方身份让队友看到您，也可以尝试暗中独立行动博取信任上车，出其不意地破坏任务。
- 【莫德雷德】：“黑老大”、“隐狼”。在【夜晚】阶段与红方队友睁眼互认（除奥伯伦），莫德雷德是唯一一个梅林看不到的强势红方角色。基本玩法是在前期潜伏取得其他玩家信任，后期在任务中作乱。
- 【爪牙】：无特殊视野的红方平民角色。在【夜晚】阶段与红方队友睁眼互认（除奥伯伦）。游戏中玩法灵活多样，可任意发挥。

# 四、游戏流程
0. 游戏准备
主持人按照附录【表1】的配置给每位玩家随机分发角色。再分发给每名玩家两张投票卡（1支持、1反对），该两张投票卡同时用于公投是否同意发车以及【5. 执行任务】时匿名投票【成功】和【失败】。
1. 夜晚阶段
全局仅一次。所有玩家闭眼，由【主持人】宣读以下夜晚流程步骤，主持人需要根据人数与角色配置跳过不需要宣读的条目。所有玩家在该过程中只会涉及到【睁眼/闭眼】和【举起/放下大拇指】两种操作。
(1) 请所有玩家闭眼，在桌面中央放置拳头，保持大拇指放下。
(2) 请除了【奥伯伦】以外的所有【红方阵营】角色睁开眼睛，互相确认彼此。
(3) 请所有玩家闭眼、放下大拇指。
(4) 请【梅林】睁眼；同时请除了【莫德雷德】以外的所有【红方阵营】角色竖起大拇指。
(5) 请所有玩家闭眼、放下大拇指。
(6) 请【派西维尔】睁眼；同时请【莫甘娜】和【梅林】竖起大拇指。
(7) 请所有玩家闭眼、放下大拇指。
(8) 请所有玩家睁眼，【夜晚】阶段结束，游戏正式开始。
2. 选出第一个队长
在首次任务开始前，由主持人随机选择一名玩家担任第一轮任务的【队长】。（若此前已进行过游戏，则第一轮队长由上局游戏中最后一位“完成组队并已得到任务结果”的队长的顺时针下一位玩家担任）。此后每轮任务的新【队长】由玩家按顺时针轮流担任。
3. 队长组队与玩家发言
由【队长】先选择出该轮【去做任务的玩家】，每轮【去做任务的玩家】的人数要求都不同，请严格参考附录【表2】。选人结束后【队长】需任选一名玩家开始顺时针或逆时针轮流发言，由队长最后发言。
4. 公投表决
所有玩家发言结束后，由【队长】再次确定【去做任务的玩家】的最终人选（可以和发言前的选择不同，也可以相同），随后由所有玩家同时【公开投票】表决【支持】与【反对】（可以竖大拇指表示），需所有玩家同时表决，且不能弃权。
若【支持】的玩家人数过半，则开始进行本轮任务（步骤5）。
若【支持】与【反对】的玩家人数相同或【反对】的玩家更多，则任务延迟（又称“流车”），由顺时针下一玩家担任【新队长】，并重复步骤3。
若连续三次流车无法进行任务，则第四次的组队队长选完人后即强制进行任务。
5. 执行任务
若任务进行，则该轮确定【去做任务的玩家】需共同进行【匿名投票】；【骑士/蓝方阵营】的玩家只能投【支持】票，而【反抗军/红方阵营】的玩家可以选择投出【支持】以暂时隐藏自己的身份，或选择投出【反对】票直接破坏本轮任务。
本轮任务的成功与否，取决于以下三个判断条件：
只有当投票全部都为【支持】票时，本轮任务成功，记【骑士/蓝方阵营】胜利1次。
若有一票及以上的【反对】时，任务都将失败，记【反抗军/红方阵营】 胜利1次。
【保护轮规则】：在7-10人局时，第四轮任务（仅第四轮）需要由2票及以上的【反对】票才会导致任务失败，若只有一张则仍记本轮任务成功。保护轮规则优先于上述两条规则。54
6. 记录本轮任务成败与否
并循环步骤3 - 5开始下一轮任务，一局游戏至多有五轮任务（五局三胜）。
7. 游戏胜利条件
若【反抗军/红方阵营】先取得3次胜利（即破坏3轮任务）则宣告【反抗军/红方阵营】获得最终胜利。
若【骑士/蓝方阵营】先取得3次胜利（即3轮任务成功）则此时【刺客】角色展示身份卡表明身份，刺客可以选择和红方阵营玩家讨论，思考并最终确定选择一名他认为是【梅林】的玩家进行刺杀，若成功刺杀到【梅林】（指认成功），则【反抗军/红方阵营】反败为胜；若刺杀失误，则【骑士/蓝方阵营】宣告最终胜利。
