# 在线商城系统 - 测试计划文档

## 1. 测试目标
确保在线商城系统各功能模块正常运行，数据一致性得到保证。

## 2. 测试范围

### 2.1 单元测试
- 用户注册测试
- 用户登录测试
- 商品创建测试
- 购物车操作测试
- 订单创建测试
- 虚拟货币交易测试

### 2.2 集成测试
- 完整购买流程测试
- 购物车结算流程测试
- 商家商品管理测试

## 3. 测试用例

### 3.1 用户模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 客户注册 | 创建用户，赠送5000软妹币 |
| 商家注册 | 创建用户，无初始余额 |
| 用户登录 | 成功登录，跳转首页 |
| 重复用户名注册 | 提示用户名已存在 |

### 3.2 商品模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 商家上架商品 | 商品创建成功，状态为上架 |
| 商家下架商品 | 商品状态变为下架 |
| 查看商品列表 | 只显示上架商品 |

### 3.3 购物车模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 添加商品到购物车 | 购物车项创建成功 |
| 重复添加同一商品 | 数量累加 |
| 更新商品数量 | 数量更新成功 |
| 删除购物车项 | 购物车项删除成功 |

### 3.4 订单模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 立即购买 | 订单创建，余额扣减，库存减少 |
| 购物车结算 | 订单创建，购物车清空 |
| 余额不足 | 提示余额不足，订单取消 |

### 3.5 虚拟货币测试
| 测试项 | 预期结果 |
|--------|----------|
| 注册赠送 | 客户获得5000软妹币 |
| 购买扣款 | 余额正确减少 |
| 商家收款 | 收到97%货款 |
| 手续费计算 | 3%手续费正确 |

## 4. 测试数据
- 3个商家用户
- 2个客户用户
- 每个商家3-5个商品
