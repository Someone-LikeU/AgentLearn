# 在线商城系统 - 测试计划文档

## 1. 测试目标
确保在线商城系统各功能模块正常运行，数据一致性得到保证。

## 2. 测试范围

### 2.1 单元测试
- 用户注册测试
- 用户登录测试
- 登录锁定测试
- 商品创建测试
- 购物车操作测试
- 订单创建测试
- 虚拟货币交易测试
- 充值功能测试
- 管理员后台测试

### 2.2 集成测试
- 完整购买流程测试
- 购物车结算流程测试
- 商家商品管理测试（含创建商品）
- 商家订单查看测试
- 管理员后台查看测试

## 3. 测试用例

### 3.1 用户模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 客户注册 | 创建用户，赠送5000软妹币 |
| 商家注册 | 创建用户，无初始余额 |
| 用户登录 | 成功登录，跳转首页 |
| 重复用户名注册 | 提示用户名已存在 |
| 登录失败5次 | 账户锁定30分钟，页面显示剩余次数 |
| 客户充值 | 输入金额后余额增加 |

### 3.2 商品模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 商家创建商品 | 商品创建成功，可在列表查看 |
| 商家上架商品 | 商品创建成功，状态为上架 |
| 商家下架商品 | 商品状态变为下架 |
| 查看商品列表 | 只显示上架商品 |

### 3.3 购物车模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 添加商品到购物车 | 购物车项创建成功 |
| 重复添加同一商品 | 数量累加 |
| 更新商品数量 | 数量更新成功 |
| 删除购物车项 | 购物车项删除成功 |

### 3.4 订单模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 立即购买 | 订单创建，余额扣减，库存减少 |
| 购物车结算 | 订单创建，购物车清空 |
| 余额不足 | 提示余额不足，订单取消 |
| 商家查看订单 | 商家可看到自己商品的订单 |

### 3.5 虚拟货币测试
| 测试项 | 预期结果 |
|--------|----------|
| 注册赠送 | 客户获得5000软妹币 |
| 购买扣款 | 余额正确减少 |
| 商家收款 | 收到97%货款 |
| 手续费计算 | 3%手续费正确 |
| 客户充值 | 输入金额后余额直接增加 |

### 3.6 管理员模块测试
| 测试项 | 预期结果 |
|--------|----------|
| 管理员登录 | 登录后跳转到管理后台 |
| 商家列表 | 展示所有商家及其商品信息 |
| 商品销量统计 | 正确显示每个商品的销量 |
| 手续费统计 | 正确显示每个商品的手续费 |
| 客户列表 | 展示所有客户，余额显示为*** |
| 导航栏 | 管理员不显示购物车和订单入口 |

## 4. 测试数据
- 3个商家用户
- 2个客户用户
- 每个商家3-5个商品
