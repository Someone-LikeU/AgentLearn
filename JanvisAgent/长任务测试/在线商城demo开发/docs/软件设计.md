## 2. 数据库设计

### 2.1 User模型（扩展Django User）
- 继承AbstractUser
- 新增字段：user_type（商家/客户）

### 2.2 Wallet模型（虚拟货币账户）
- user: OneToOneField(User)
- balance: DecimalField(max_digits=10, decimal_places=2)
- created_at: DateTimeField
- updated_at: DateTimeField

### 2.3 Product模型（商品）
- name: CharField(max_length=200)
- description: TextField
- price: DecimalField(max_digits=10, decimal_places=2)
- stock: IntegerField(default=0)
- seller: ForeignKey(User)
- is_active: BooleanField(default=True)
- created_at: DateTimeField

### 2.4 CartItem模型（购物车项）
- user: ForeignKey(User)
- product: ForeignKey(Product)
- quantity: IntegerField(default=1)
- created_at: DateTimeField

### 2.5 Order模型（订单）
- user: ForeignKey(User)
- total_amount: DecimalField(max_digits=10, decimal_places=2)
- status: CharField(choices=['pending', 'completed', 'cancelled'])
- created_at: DateTimeField

### 2.6 OrderItem模型（订单项）
- order: ForeignKey(Order)
- product: ForeignKey(Product)
- quantity: IntegerField
- price: DecimalField(max_digits=10, decimal_places=2)

## 3. 业务逻辑设计

### 3.1 注册流程
1. 用户填写注册表单
2. 创建User对象
3. 如果是客户类型，创建Wallet对象，余额5000

### 3.2 购买流程
1. 客户选择商品
2. 添加到购物车或直接购买
3. 系统检查余额是否充足
4. 创建订单和订单项
5. 扣减客户余额
6. 增加商家余额（扣除3%手续费）
7. 减少商品库存
8. 清空购物车（如果是购物车结算）

### 3.3 手续费计算
- 手续费 = 商品价格 × 3%
- 商家实际收入 = 商品价格 × 97%

## 4. 安全设计
- 使用Django内置CSRF保护
- 使用Django内置用户认证
- 使用事务处理订单操作
- 使用Decimal处理货币计算
