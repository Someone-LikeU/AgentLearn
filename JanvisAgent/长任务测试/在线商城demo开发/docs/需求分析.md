# 在线商城系统 - 需求分析文档

## 1. 项目概述
开发一个在线商城系统demo，支持商家和客户两种类型的用户登录，支付系统使用虚拟货币（软妹币）在系统内进行结算。

## 2. 功能需求

### 2.1 用户系统
- 支持管理员、商家和客户三种角色
- 用户注册/登录/登出功能
- 用户个人信息管理
- 客户注册后赠送5000软妹币
- 客户可在个人中心充值余额
- 登录失败5次后锁定30分钟，页面显示剩余尝试次数

### 2.2 商品系统
- 商家可创建新商品
- 商家可上架/下架商品
- 商品信息展示（名称、描述、价格、库存、图片）
- 商品列表浏览

### 2.3 购物车系统
- 客户可将商品添加到购物车
- 购物车商品数量调整
- 购物车商品删除
- 购物车批量结算

### 2.4 订单系统
- 立即购买功能
- 购物车结算功能
- 客户订单历史查看
- 商家可查看自己商品的订单
- 订单状态管理

### 2.5 虚拟货币系统
- 软妹币账户管理
- 注册赠送5000软妹币
- 客户可在个人中心充值余额
- 购买商品扣款
- 商家销售收款（扣除3%手续费）

### 2.6 管理员系统
- 管理员使用专用账号登录，登录后跳转到管理后台
- 管理员后台展示商家列表（含商品名称、价格、销量、手续费）
- 管理员后台展示客户列表（余额用***表示）
- 管理员导航栏仅显示"管理后台"，不显示购物车和订单

## 3. 非功能需求
- 系统安全性：防止SQL注入、XSS攻击
- 数据一致性：使用事务处理订单
- 用户体验：响应式界面设计

## 4. 技术栈
- 后端：Python 3.10+ + Django 4.x
- 数据库：SQLite
- 前端：HTML5 + CSS3 + JavaScript
