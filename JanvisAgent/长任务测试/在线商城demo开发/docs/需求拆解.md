# 在线商城系统 - 需求拆解文档

## 1. 用户模块拆解

### 1.1 用户注册
- 注册表单（用户名、密码、邮箱、用户类型）
- 用户类型选择（商家/客户）
- 客户注册自动创建5000软妹币账户

### 1.3 个人中心
- 客户查看个人信息和余额
- 客户充值余额功能（输入金额后直接成功）

## 2. 商品模块拆解

### 2.1 商品模型
- 商品基本信息（名称、描述、价格、库存）
- 商品状态（上架/下架）
- 商品与商家关联

### 2.2 商品管理
- 商家商品列表
- 商家创建新商品
- 商品上架/下架操作
- 商品信息编辑

## 3. 购物车模块拆解

### 3.1 购物车模型
- 购物车项（用户、商品、数量）
- 同一商品合并逻辑

### 3.2 购物车操作
- 添加商品
- 更新数量
- 删除商品
- 清空购物车

## 4. 订单模块拆解

### 4.1 订单模型
- 订单基本信息（用户、总金额、状态、创建时间）
- 订单项（商品、数量、单价）

### 4.2 订单流程
- 立即购买 → 创建订单 → 扣款 → 完成
- 购物车结算 → 创建订单 → 扣款 → 清空购物车 → 完成

## 6. 管理员模块拆解

### 6.1 管理员登录
- 使用 admin/admin123 登录
- 登录后跳转到管理后台，不显示购物车和订单入口

### 6.2 商家管理
- 查看所有商家列表
- 查看每个商家的商品信息（名称、价格、销量、手续费）
- 查看合计手续费

### 6.3 客户管理
- 查看所有客户列表
- 客户余额用***表示（隐私保护）

### 5.1 账户模型
- 用户账户（用户、余额）
- 余额使用Decimal类型

### 5.2 交易逻辑
- 客户购买：余额减少
- 商家销售：收到货款扣除3%手续费
- 系统收入：手续费收入
- 客户充值：输入金额后直接增加余额
