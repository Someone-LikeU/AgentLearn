# 在线商城系统 - 需求拆解文档

## 1. 用户模块拆解

### 1.1 用户注册
- 注册表单（用户名、密码、邮箱、用户类型）
- 用户类型选择（商家/客户）
- 客户注册自动创建5000软妹币账户

### 1.2 用户登录
- 登录表单验证
- Session管理
- 角色权限控制

## 2. 商品模块拆解

### 2.1 商品模型
- 商品基本信息（名称、描述、价格、库存）
- 商品状态（上架/下架）
- 商品与商家关联

### 2.2 商品管理
- 商家商品列表
- 商品上架/下架操作
- 商品信息编辑

## 3. 购物车模块拆解

### 3.1 购物车模型
- 购物车项（用户、商品、数量）
- 同一商品合并逻辑

### 3.2 购物车操作
- 添加商品
- 更新数量
- 删除商品
- 清空购物车

## 4. 订单模块拆解

### 4.1 订单模型
- 订单基本信息（用户、总金额、状态、创建时间）
- 订单项（商品、数量、单价）

### 4.2 订单流程
- 立即购买 → 创建订单 → 扣款 → 完成
- 购物车结算 → 创建订单 → 扣款 → 清空购物车 → 完成

## 5. 虚拟货币模块拆解

### 5.1 账户模型
- 用户账户（用户、余额）
- 余额使用Decimal类型

### 5.2 交易逻辑
- 客户购买：余额减少
- 商家销售：收到货款扣除3%手续费
- 系统收入：手续费收入
